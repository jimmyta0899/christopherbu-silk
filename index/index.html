Calculators

Four tools that do the arithmetic a quotation needs. They run in the browser and use the published constants: 1 momme = 4.340 g/m², 1 oz/yd² = 33.906 g/m², tex = denier / 9, Nm = 1000 / tex.

  • Momme, g/m² and oz/yd² converter

    Converts between the three weight units buyers quote in.

  • Silk yarn count converter

    Denier, tex, decitex and Nm, with the constants each uses.

  • Order weight calculator

    Turns meters, width and momme into the kilograms a shipment is charged on.

  • Specification comparison

    Puts two fabrics side by side on weight, width and construction.
