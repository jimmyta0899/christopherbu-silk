HS 5002: Export Document Mismatches

A raw silk shipment can clear production on time and still wait at the port. When that happens, the delay is usually about the paper, not the yarn. Five documents travel with the goods. If one figure differs between two of them, a reviewer can hold the shipment. The fix is not a faster loom. It is a document set that agrees with itself before the goods move.

Most confusion sits with one code. Raw silk (not thrown) falls under HS heading 5002. The exact subheading is confirmed in the written quotation and the shipping documents, never one fixed code for every order. Buyers who treat 5002 as a complete code, or who fill each form at a different moment, end up with papers that disagree. This article shows where the figures come from, names the five documents, and gives one method to align them. The aim is a shipment a buyer can release without a document query.

Key takeaways

  • ›Raw silk (not thrown) falls under HS heading 5002. The exact subheading is confirmed in the written quotation and shipping documents, never one fixed code for every order.
  • ›The export set has five documents: spec sheet, lab dip, inspection report, packing list and certificate of origin. Each fixes a different fact about one order.

  • ›Reconcile every figure against the written quotation before dispatch. Certificate numbers come with the quotation and shipping documents, so each scope can be checked before approval.

Why a raw silk shipment stalls at the document stage

The hold is a reconciliation problem, rarely a quality problem. A buyer approves a sample, confirms the spec, and sees the yarn packed on time. The goods are ready. Then the paperwork is checked at the border, and one figure does not match another. The yarn is fine. The papers are not.

Consider a first bulk order, for example. The buyer holds a written quotation, a spec sheet, a lab dip, an inspection report, a packing list and a certificate of origin. Each document was made at a different step. The spec sheet was published before the order. The packing list was drawn up when the bales were weighed. If nobody lines them up, the same fact can appear twice with two values. A buyer comparing several suppliers in one week rarely has time to notice.

The five documents are listed on the raw silk spec page and the downloadable spec sheet. They cover the product, the color, the test result, the packing and the origin. Customs reviews them as one set. A weight on one form that differs from the bale count on another is a question someone must answer in writing.

That is why the classification sits inside the commercial group of the written quotation, next to incoterms, lead time and packing. The trade and shipping terms page states the HS rule alongside the shipping terms. A buyer who reads only the product lines misses the field that decides how the goods are declared.

The one root cause: figures fixed at different moments

One root cause sits behind most export-document delays. The figures on the papers come from two different moments, and nobody checks them against one reference before the goods move. Some are planning values published on the spec sheet. Others are final values fixed for one order in the written quotation and the shipping documents. Copy a planning value into a final form, or assume one code covers every order, and the set disagrees with itself.

A planning value is a figure published on the spec sheet for planning, checked against current availability before quotation. A final value is the figure fixed for one order in the written quotation and the shipping documents. The raw silk spec page calls its own numbers planning values. Confusing the two produces a discrepancy that is not really there.

HS heading 5002 is stable, the subheading is not

Heading 5002 is fixed. The subheading is not. An HS heading is the four-digit group in the Harmonized System used to classify goods. Raw silk (not thrown) falls under heading 5002 (World Customs Organization, Harmonized System heading 5002, cited on the trade terms page, retrieved 2026-11-06). The exact subheading is confirmed in the written quotation and shipping documents, never one fixed code for every order.

This is the assumption a buyer brings most often. A code that worked on the last order is copied onto the next one. The spec sheet does not publish a fixed subheading. The written quotation carries the applicable one for that shipment. Read the subheading on the quotation, then check that the same value appears on the shipping documents. The spec sheet names the heading. The order documents fix the subheading. A code copied from an earlier order may not be the one confirmed for this one.

What the same silk became one stage later

The heading names a specific input, and the site records where it went. Raw silk (not thrown) falls under HS heading 5002 (World Customs Organization, Harmonized System heading 5002). The standard denier is 20/22D, with grades from 4A to 6A under GB/T 1797-2008 (Standardization Administration of China, 2008). Those figures describe yarn as it leaves reeling and grading, still greige, still not thrown. The 20/22D raw silk graded 4A to 6A under GB/T 1797-2008 that falls under heading 5002 is the greige base yarn the site links to the Forbidden City jacquard gown Fan Bingbing wore to the 2015 Met Gala. There the graded, even yarn carried a motif woven into the cloth on the loom. The site states that the dupioni cut for Fan Bingbing in 2013 came from this silk base. It traces that jacquard and the Snow Plum Blossom dress Paz Vega wore to the 2018 Oscars to the same base (about the supplier, 2026). The label's own production records place the silk for these gowns in Yizhou. The site describes the 2013 dupioni pieces as cut from the same dupioni the label supplies as greige today. In the 2013 skirts the slubbed plain weave held the shape. In the 2015 gown the woven motif depended on yarn even enough to keep a clean pattern. Both are what the yarn at the 5002 stage became after weaving.

A finished woven gown is a different good from the raw silk yarn the heading describes. It sits further along the same Yizhou chain, after weaving turns the yarn into dupioni or jacquard and the cloth is cut and sewn into a gown. That stage boundary is exactly why the written quotation and the shipping documents confirm the exact subheading per order rather than leave it assumed. The heading tells a buyer which family of goods the yarn belongs to. Only the order documents fix the classification for the consignment actually being declared. Carrying a code across from a finished gown to the yarn, or from one order to the next, is the assumption those documents exist to prevent.

Planning values and final values are different documents

The spec sheet and the written quotation answer different questions. The spec sheet gives the standard denier 20/22D, with 13/19D also in regular supply and 27/29D on request, and typical packing of 60 kg per bale. Those are planning values for a program. The written quotation fixes the denier, grade, packing and applicable HS subheading for one order.

Grading follows GB/T 1797-2008, with moisture controlled below 11% (Standardization Administration of China, 2008). Grades span 4A, 5A and 6A. Grade availability is confirmed by variety in the quotation, not from the tier list alone. The product range lists four varieties, but the quotation is where the chosen variety and its grade become final. Compare a planning value with a final value and you will find a mismatch that is not real. Keep both documents, and label which is which.

The five export documents and what each one fixes

The export set is a checklist of five documents. Each one fixes a different fact about the same order. Read them as a set, not as five separate forms. The table below is the checklist a buyer can use before dispatch.

Spec sheet, lab dip and inspection report

Three documents cover what the yarn is and how it was checked. The spec sheet publishes the standard and the planning values. A lab dip records the approved color when yarn is dyed to order from a standard shade card or a custom color. Greige (undyed) yarn has no lab dip, since there is no color to approve. The inspection report records the test result against a named test method (GB/T 1797-2008, Standardization Administration of China, 2008).

A sample without a named test method proves only that the sample looked right. The sample request page covers the swatch that should arrive with the quotation. On the report, the lot mark ties the result to one production lot. Keep the swatch, the method reference and the report together. Check that the method on the report is the one named in the quotation.

Packing list and certificate of origin

Two documents describe the physical shipment. The packing list states the export cartons or bales and their weights. Typical packing is 60 kg per bale, and luxury silk yarn comes in 5 kg bundles (downloadable spec sheet, 2026). The certificate of origin records where the goods were produced.

A packing list is the document that lists the cartons or bales and their weights for one shipment. A certificate of origin is the document that records the production origin of the goods. Both should agree with the written quotation. Yizhou is a geographic origin, and bulk moves FCA Yizhou as a preferred term. The origin on the certificate and the incoterm on the quotation should describe the same place. The trade and shipping terms page lists the four bulk terms in one place.

A cross-document reconciliation method

One method turns the document set into a decision tool. Name one reference document, then check every figure on the other papers against it before dispatch. A reconciliation is a line-by-line check that every figure on the export documents matches the value fixed in the written quotation and the shipping documents. The written quotation is the reference. The shipping documents carry the final values once issued.

The methodology is deliberately plain. For each of the five documents, ask two questions. Which value does this document fix? Where was that value confirmed? A figure with no source document and no confirmation date is a promise, not a value. Write the answer down, one line per document.

Take the HS subheading, for instance. '5002' on a line is a heading. The subheading that satisfies it is the one confirmed in the written quotation and the shipping documents for that order. Working backwards gives a buyer two checks. Read the subheading on the quotation, then confirm it matches the shipping documents. The full field list on the spec page is the reference for the commercial group.

The same move works on packing. '60 kg per bale' is a planning value. The final bale specification sits in the written quotation and the packing list. If the packing list shows a weight that differs from the quotation, the field stays open until it is confirmed in writing. Keep the downloadable raw silk spec sheet beside the quotation. Raise any figure whose source is not obvious with the seller in writing. A figure that needs a phone call to explain is a figure that should be on paper.

Two internal checks help. For example, a buyer shipping to the EU asks which test report covers a destination-market claim, then checks that report against the certificate scope. If any of the three is missing, the row stays open. Work down the checklist once and mark each row as matched or still open.

Where the shipping figures come from

Every shipping figure traces to a published document. The trade and shipping terms page gathers the commercial ones. Bulk ships FOB Nansha, FOB Yantian, FOB Qinzhou or FCA Yizhou. Samples go by DHL worldwide or a designated courier. Payment for bulk is T/T, 30% deposit and 70% against the Bill of Lading (trade terms, 2026).

Lead time is 15-25 working days for eligible regular bulk orders. Sample, specification, deposit and material availability all have to be confirmed first. The binding schedule sits in signed order documents (trade terms page, 2026). The clock does not start at enquiry. A buyer who reads the window as a promise from day one will misread the packing list. The signed schedule is the evidence. Order approval is when it becomes binding.

Finish is greige (undyed) or dyed to order from a standard shade card or a custom color. Both are available on all products. A lab dip exists only for a shade dyed to order, so a greige order should not carry one.

Check certificate numbers and scope before dispatch

A certificate claim is a scope claim, and it needs a public check. The written quotation and the shipping documents carry the certificate numbers, so a buyer can fact check each one against the issuing body before approval. The number alone proves nothing until its scope matches the goods.

The certificate check page lists two entry points. The OEKO-TEX label check lets a buyer confirm a label and its scope (OEKO-TEX Association, retrieved 2026-11-06). The GOTS public license database does the same for organic status (Global Organic Textile Standard, retrieved 2026-11-06). Raw silk grading follows GB/T 1797-2008 (Standardization Administration of China, 2008). Certification for qualified buyer review covers GOTS, OEKO-TEX STANDARD 100 Class II, China Organic and quality-system files, each within its own listed scope.

Destination-market compliance works the same way. Buyers check California Prop 65 and EU textile safety requirements against product-specific test reports. Both sides confirm them in writing before order approval. For instance, a buyer can ask which test report covers a given claim, then check that report against the certificate scope. That review is a field on the quotation, not a promise made after shipment. If any of the three is missing, the row stays open.

A pre-dispatch checklist

Work through these six lines before you release any raw silk shipment. The list is short enough to use at a desk and specific enough to catch a document mismatch.

  • Name the written quotation as the reference and keep the spec sheet and signed order documents beside it.
  • Read the HS subheading on the quotation, then confirm it matches the shipping documents. Heading 5002 alone is not a classification.
  • Check the spec sheet, lab dip, inspection report, packing list and certificate of origin as one set, not five forms.
  • Confirm the test method reference and ask which inspection report it governs.
  • Reconcile bale weights, lot marks, production origin and certificate numbers against the written quotation.
  • Fact check every certificate number against the public database, and confirm destination-market compliance in writing.

Before you approve dispatch, request a written quotation and ask for the five-document set reconciled against it. A set that agrees with itself is a shipment a buyer can release.

No. Raw silk (not thrown) falls under HS heading 5002. The written quotation and the shipping documents confirm the exact subheading, since it depends on the goods and the destination. A single fixed code for every order is not how the documents work.

Five: the spec sheet, lab dip, inspection report, packing list and certificate of origin. Greige (undyed) yarn has no lab dip, since there is no color to approve. The other four documents still apply.

When are certificate numbers provided?

With the written quotation and the shipping documents. Both sides confirm certification in writing before order approval, within each document's listed scope. A buyer can then check the number against the issuing body's public entry before signing.
